# Backend source

This directory records the Lightsail application code. The frontend at the repository root uses the existing Lightsail HTTPS API and Firebase login. Vercel serves the frontend; it does not run this backend.

Environment files, credentials, databases, knowledge-base data, uploads, virtual environments and trained model binaries are intentionally excluded. Use the separate Lightsail update bundle and retain the server environment, runtime data and model cache when deploying.
